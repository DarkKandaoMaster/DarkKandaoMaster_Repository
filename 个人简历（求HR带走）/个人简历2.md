### OmicsInferenceDeck｜多组学癌症亚型识别算法评估平台（Python 全栈 · 独立开发）
2026.02 至今｜全程独立开发｜已部署上线、实验室在用
仓库 https://github.com/DarkKandaoMaster/OmicsInferenceDeck ｜ 在线 http://omicsid.natapp1.cc
视频 https://www.bilibili.com/video/BV1FD786aEu9 ｜ 文档 http://omicsid.natapp1.cc/OmicsInferenceDeck文档.pdf
- 解决的真实痛点：算法研究者发论文前，需手写大量评估指标、画"论文级"图表、复现经典算法做基线，
  重复劳动极重。我把这套流程产品化为一键平台，研究者上传算法结果即自动产出指标与图表。
- 后端（Python / FastAPI，5232 行）：前后端分离架构，按业务拆分为 11 个路由模块；
  核心接口基于 async/await 异步处理大文件流上传与长耗时分析任务；通过 FastAPI lifespan
  挂载后台定时清理任务管理会话临时文件。
- 可扩展算法层：用「抽象基类 + 注册表」模式封装 7 种内置聚类算法（K-means/谱聚类/层次聚类/
  SNF/NEMO/PIntMF/MOSD），新增算法只需继承基类并注册，下游指标与绘图无需改动；
  支持批量参数扫描，并据此渲染 2D/3D 参数敏感性曲面图。
- 跨语言工程：Python 作为调度层，通过子进程整合 R 生态（lifelines、GSEApy 及多个 R 包）完成
  生存分析、差异表达、GO/KEGG 富集等生信计算；中间结果以 Parquet 落盘供多接口复用。
- 科研严谨性：对输入做严格校验（空值/格式/标签一致性），绝不静默修改用户数据，不合规即明确报错，
  保证结果可复现；图表既可在线交互微调，也可导出原生绘图脚本在本地复现。
- 成果：13000+ 行业务代码（后端 Python 5232 + R 2978 / 前端 5108），已部署至实验室服务器
  供研究生日常使用；项目获校级大创（学院第一）、2026 网络技术挑战赛省级奖。

### anime-face-clipper｜视频人脸事件检测与智能截取流水线（Python · AI/CV）
2026.06｜全程独立开发｜https://github.com/DarkKandaoMaster/anime-face-clipper
- 目标：从视频中自动定位并截取「15 秒内陆续出现 ≥13 张清晰、可识别人脸」的片段。
- 端到端 CV 流水线（抽帧→检测→过滤→跟踪→选段→截取）：ffmpeg 定间隔抽帧 →
  基于 ONNX Runtime 运行 YOLOv8 人脸检测模型 → 用裁剪图的拉普拉斯方差做清晰度过滤 →
  以相邻帧 IoU 重叠串联人脸轨迹、并用 HSV 颜色直方图检测镜头切换强制断轨（保证"同位置不同角色"
  计为新事件）→ 滑动窗口统计轨迹起点数选出合格片段 → ffmpeg 精确截取。
- 工程设计：检测器层用「抽象基类 + 注册表 + 装饰器」实现可插拔，下游只消费稳定的 Detection
  数据契约，扩展到检测动物/物体等新目标只需新增一个子类，无需改动跟踪与截取逻辑。

  延迟片刻再粘贴，图片输出同样处理，彻底消除丢行。
