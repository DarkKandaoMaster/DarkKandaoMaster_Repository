### anime-face-clipper｜动漫视频人脸事件检测与截取（Python）
仓库：https://github.com/DarkKandaoMaster/anime-face-clipper
2026.06｜独立开发
技术栈：Python、YOLOv8、ONNX Runtime、OpenCV、FFmpeg

项目简介：该项目用于辅助从动漫视频中筛选人脸集中出现的片段，减少人工逐段观看和定位的时间。程序输入原视频后，会输出符合条件的视频片段，以及检测框、轨迹、代表人脸裁剪图等便于检查的中间结果。

- 使用 YOLOv8、ONNX Runtime 进行动漫人脸检测，并根据检测置信度、人脸尺寸和拉普拉斯方差过滤部分低质量结果，减少远景、模糊帧和误检对后续统计的影响。
- 使用相邻帧 IoU 对检测框进行简单匹配，形成一次人脸出现的轨迹；同时通过 HSV 直方图相关性辅助判断镜头切换，并在切镜位置断开轨迹，降低跨镜头错误关联的情况。
- 使用 15 秒滑动窗口统计窗口内新出现的人脸轨迹数量，并筛选互不重叠的候选时段。
- 使用 FFmpeg 根据筛选出的时间段从原视频中截取片段，并保存检测结果 JSON、轨迹信息、代表人脸裁剪图和标注帧，方便后续人工复核。
- 以统一的 Detection 数据结构连接检测、过滤、跟踪和截取流程；通过抽象基类、注册表和装饰器实现检测器可替换，后续如需检测其他目标时，可以复用后续处理流程。

### OmicsInferenceDeck｜多组学癌症亚型识别算法评估平台（Python 全栈）
仓库：https://github.com/DarkKandaoMaster/OmicsInferenceDeck ｜ 在线：http://omicsid.natapp1.cc
2026.02-至今｜独立开发
技术栈：Python、FastAPI、Pandas、scikit-learn、R、Vue 3、Nuxt 4、TypeScript、Tailwind CSS

项目简介：面向多组学癌症分型研究中“算法复现、指标计算和论文图表绘制流程分散”的问题，将常用分析步骤整理为浏览器端工作流，便于统一运行、比较和导出结果。

- 使用 FastAPI、Uvicorn 构建 REST 后端，按数据接入、算法运行、指标评估、生存分析、差异表达、功能富集、绘图与会话清理拆分路由；通过 Pydantic 校验请求参数，使用 Pandas、NumPy、SciPy、scikit-learn 完成数据处理、降维聚类与统计计算。
- 设计 Python/R 协同计算流程：Python 负责任务编排、数据校验和接口封装，通过 Rscript 调用 R 侧算法及生物统计工具；使用 Parquet 传递中间数据，封装 K-means、Spectral、SNF 等 7 种聚类方法，并统一算法输入、参数和结果格式。
- 以浏览器生成的 UUID 区分用户会话，将上传数据、中间结果与导出文件按会话目录管理，并设置过期目录清理。
- 使用 Vue 3、Nuxt 4、TypeScript 构建分析工作台，以 Axios 封装接口通信，并通过 Composables 拆分会话、运行控制、数据状态及差异分析等业务状态；用户可完成文件上传、参数配置、运行反馈、结果预览和图表导出。
- 支持数学聚类指标、临床统计、生存分析、差异表达及 GO/KEGG 富集分析，生成降维聚类图、Kaplan-Meier 曲线、火山图、热图等结果；图表可导出 PNG、SVG、PDF，便于后续论文整理和结果复现。
