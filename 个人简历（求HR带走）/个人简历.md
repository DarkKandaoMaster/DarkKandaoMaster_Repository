### OmicsInferenceDeck｜多组学癌症亚型识别算法评估平台（Python 全栈）
2026.02-至今｜独立开发
仓库 https://github.com/DarkKandaoMaster/OmicsInferenceDeck ｜ 在线 http://omicsid.natapp1.cc
视频 https://www.bilibili.com/video/BV1FD786aEu9 ｜ 文档 http://omicsid.natapp1.cc/OmicsInferenceDeck文档.pdf
技术栈：Python、FastAPI、R、Vue 3、Nuxt、TypeScript
- 面向癌症亚型识别算法的评估场景，将指标计算、基线算法复现和结果绘图整合为一套 Web 平台；用户上传算法结果后，可完成统计评估并生成相应图表。
- 使用 FastAPI 搭建前后端分离服务，后端按业务划分为 11 个路由模块；基于 async/await 处理大文件流式上传和分析任务，并通过 lifespan 管理临时文件的定时清理。
- 采用抽象基类与注册表封装 K-means、谱聚类、SNF、NEMO 等 7 种聚类算法，使算法接入与指标、绘图模块解耦；支持批量参数扫描及 2D/3D 参数敏感性可视化。
- 以 Python 调度 lifelines、GSEApy 及 R 包，完成生存分析、差异表达和 GO/KEGG 富集分析；使用 Parquet 保存中间结果，供多个接口复用。
- 对空值、文件格式和样本标签一致性进行输入校验；支持图表在线调整，并可导出绘图脚本用于本地复现。
- 项目包含约 1.3 万行业务代码（Python 5232 行、R 2978 行、前端 5108 行）。已完成早期迭代积累，进入更加稳定、持续的更新阶段。
- 项目已部署至实验室服务器，供研究生日常使用。

### anime-face-clipper｜视频人脸事件检测与截取（Python）
2026.06｜独立开发
仓库 https://github.com/DarkKandaoMaster/anime-face-clipper
技术栈：Python、YOLOv8、ONNX Runtime、OpenCV、FFmpeg
- 用于从视频中截取 15 秒内陆续出现不少于 13 张清晰可识别人脸的片段。
- 使用 ffmpeg 定间隔抽帧，通过 ONNX Runtime 运行 YOLOv8 人脸检测模型，并以拉普拉斯方差过滤模糊人脸；根据相邻帧 IoU 关联轨迹，结合 HSV 颜色直方图检测镜头切换，减少跨镜头误关联。
- 使用滑动窗口统计人脸轨迹起点并筛选候选时段，最后由 ffmpeg 完成视频截取。
- 检测器采用抽象基类、注册表和装饰器组织，下游模块依赖统一的 Detection 数据结构，便于替换模型或扩展检测目标。
